## [0.1.0] - 2026-05-11

### 首次发布 🚀

#### 新增功能
- ✅ 记忆宫殿架构 - 基于人类记忆原理的 AI 记忆系统
- ✅ 永久记忆存储 - 支持无限记忆条目
- ✅ 智能检索优化 - 毫秒级检索速度
- ✅ 记忆抽屉系统 - 模块化设计，灵活配置
- ✅ 零依赖安装 - pip install 即可使用
- ✅ 企业级应用 - 支持大规模部署
- ✅ 高度可定制 - 满足各种个性化需求

#### 性能表现
- 支持百万级记忆条目
- 毫秒级检索速度
- 跨平台兼容（macOS/Linux/Windows）
- 低内存占用

#### 核心命令
- `claw-memory init` - 初始化系统
- `claw-memory create` - 创建记忆宫殿
- `claw-memory add` - 添加记忆
- `claw-memory recall` - 检索记忆
- `claw-memory list` - 查看所有记忆
- `claw-memory export` - 导出记忆
- `claw-memory delete` - 删除记忆
- `claw-memory archive` - 归档记忆

#### Python API
- MemoryDB 核心类
- create() - 创建记忆抽屉
- add() - 添加记忆
- recall() - 检索记忆
- delete() - 删除记忆
- export() - 导出记忆
- list() - 列出所有记忆

1. pip install openclaw-memory-pro
2. claw-memory init

4. 开始使用记忆宫殿！
