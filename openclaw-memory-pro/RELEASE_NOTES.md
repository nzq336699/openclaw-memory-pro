### 核心命令

- `claw-memory init` - 初始化系统
- `claw-memory create` - 创建记忆宫殿
- `claw-memory add` - 添加记忆
- `claw-memory recall` - 检索记忆
- `claw-memory list` - 查看所有记忆
- `claw-memory export` - 导出记忆
- `claw-memory delete` - 删除记忆
- `claw-memory archive` - 归档记忆

### Python API

- MemoryDB 核心类
- create() - 创建记忆抽屉
- add() - 添加记忆
- recall() - 检索记忆
- delete() - 删除记忆
- export() - 导出记忆
- list() - 列出所有记忆

### 快速开始

```bash
pip install openclaw-memory-pro
claw-memory init
claw-memory create --wing "work" --room "main" --drawer "notes"
claw-memory add "work:notes" "今天学习了 OpenClaw-Memory-Pro"
```
