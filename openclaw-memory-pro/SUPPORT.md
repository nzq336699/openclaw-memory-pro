## 📖 常见问题

### Q1: 如何安装？
**A:** `pip install openclaw-memory-pro`

### Q2: 如何创建记忆宫殿？
**A:** `claw-memory init` 然后 `claw-memory create --wing "work" --room "main" --drawer "notes"`

### Q3: 如何添加记忆？
**A:** `claw-memory add "work:notes" "今天的笔记内容"`

### Q4: 如何检索记忆？
**A:** `claw-memory recall "关键词"`

### Q5: 如何导出记忆？
**A:** `claw-memory export output.json`
