# 🦞 OpenClaw: Your Personal AI Assistant — The Lobster Way

## What is OpenClaw?

**OpenClaw** is a personal AI assistant you run on your own devices. It answers you on the channels you already use — WhatsApp, Telegram, Slack, Discord, Signal, iMessage, and more. It can speak and listen on macOS/iOS/Android, and can render a live Canvas you control.

## Why OpenClaw?

- **Local-first** — Run on your own devices, your own data
- **Multi-channel** — Connect to your existing communication tools
- **Multi-agent** — Route tasks to specialized sub-agents
- **Voice Wake** — Wake up with voice commands
- **Live Canvas** — Visual workspace for complex tasks

## Getting Started

```bash
openclaw onboard --install-daemon
```

## Supported Channels

- WhatsApp, Telegram, Slack, Discord
- Google Chat, Signal, iMessage
- IRC, Microsoft Teams, Matrix
- Feishu, LINE, Mattermost
- Nextcloud Talk, Nostr, Synology Chat
- Tlon, Twitch, Zalo, WeChat, QQ, WebChat

## Key Features

- **Gateway** — Single control plane for sessions, channels, tools
- **Sessions** — Isolated agent runs for each task
- **Tools** — File system, browser, system commands, messaging
- **Skills** — Specialized capabilities (healthcare, finance, IT, etc.)
- **Nodes** — Control paired devices (cameras, speakers, etc.)
- **Cron** — Scheduled tasks and wake events

## Security Model

- Default tools run on host for main session
- Group safety with sandboxing for non-main sessions
- Explicit opt-in for unknown DM senders
- Full control over permissions
