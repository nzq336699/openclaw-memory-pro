## Post 3: Tutorial Series Post 1

```
🦞 Tutorial: Getting Started with OpenClaw in 5 Minutes

Want to try OpenClaw? Here's a quick 5-minute tutorial:

Step 1: Install
```bash
openclaw onboard --install-daemon
```

Step 2: Connect channels
```bash
openclaw channel connect --platform slack --token <your-token>
```

Step 3: Spawn a subagent
```bash
openclaw agent --task "Summarize this document"
```

Step 4: Use voice wake
- Say "Hey, OpenClaw" on macOS/iOS
- Or use the app on Android

Step 5: Explore the Canvas
- Click the menu bar icon
- See your active sessions
- Drag and drop tasks

📚 Full documentation: https://docs.openclaw.ai/start
