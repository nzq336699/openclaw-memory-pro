# 📚 教程模板 1: 基础使用

## 🎯 适用人群
- 新手开发者
- AI 爱好者
- 记忆管理需求者

## 🚀 快速开始

```bash
# 1. 安装
pip install openclaw-memory-pro

# 2. 初始化
from claw_memory import MemoryDB
db = MemoryDB.from_home_dir()

# 3. 创建记忆抽屉
drawer = db.create(wing="work", room="main", drawer="notes")

# 4. 添加记忆
db.add("work:main:notes", "今天的学习笔记")

# 5. 检索记忆
results = db.recall("笔记", limit=5)
```

## 💡 使用技巧

- 按场景分类记忆（工作/学习/生活）
- 使用关键词优化检索
- 定期整理记忆抽屉
