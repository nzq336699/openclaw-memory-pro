## 🏢 企业级功能

### 1. 知识管理
```python
# 企业知识库
corporate = db.create_team("企业知识库")
corporate.add_wing("研发", room="核心", drawer="技术方案")
corporate.add_wing("市场", room="公开", drawer="产品文档")

# 跨部门检索
all_knowledge = corporate.cross_recall(keywords="技术方案", limit=100)
```

### 2. 权限分级
```python
# 管理员权限
admin = corporate.create_user("admin", role="super_admin")

# 部门权限
dev_team = corporate.create_team("研发团队")
dev_team.set_permission("研发", can_read=True, can_write=True)
```

### 3. 自动文档
```python
# 自动生成项目文档
docs = db.auto_generate_docs(
    source_folder="./project",
    output_format="markdown",
    include_changelog=True
)
```
