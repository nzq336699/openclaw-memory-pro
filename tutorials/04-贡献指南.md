## 📝 贡献方式

### 1. 提交 Issue（推荐新手）

**创建 Issue 的步骤**：

1. 查看 [现有 Issues](https://github.com/nzq336699/openclaw-memory-pro/issues)
2. 确认问题未被解决
3. 创建新 Issue
4. 提供详细信息

**Issue 模板**：

```markdown
## 问题类型
- [ ] Bug 报告
- [ ] 功能建议
- [ ] 文档改进
- [ ] 其他问题

## 问题描述
**期望行为**: [描述你期望的行为]

**实际行为**: [描述实际遇到的问题]

## 环境信息
- **操作系统**: [系统 + 版本]
- **软件版本**: [版本号]
- **安装方式**: [pip/git/其他]

## 复现步骤
1. 步骤 1
2. 步骤 2
3. ...

## 预期结果
[描述预期结果]

## 实际结果
[描述实际结果]

## 附加信息
- 截图/日志（可选）
- 相关 issue 链接
- ...
```

**优先级分类**：

| 优先级 | 标准 | 响应时间 |
|-------|------|----------|
| 🔴 **高** | 严重 bug, 安全漏洞 | <24 小时 |
| 🟡 **中** | 功能建议，一般 bug | <48 小时 |
| 🟢 **低** | 文档改进，其他建议 | <7 天 |

### 2. 提交 Pull Request（中级）

**贡献代码的流程**：

```bash
# 1. Fork 项目
git clone https://github.com/nzq336699/openclaw-memory-pro.git
cd openclaw-memory-pro

# 2. 创建分支
git checkout -b feature/your-feature-name

# 3. 进行修改
# 编辑代码、添加功能、修复 bug 等

# 4. 提交更改
git add .
git commit -m "feat: 添加新功能描述"

# 5. 推送到仓库
git push origin feature/your-feature-name

# 6. 创建 Pull Request
# 在 GitHub UI 上创建 PR
```

**提交规范**：

- ✅ 使用 `Conventional Commits` 规范
- ✅ 提供清晰的提交消息
- ✅ 添加必要的测试
- ✅ 更新文档

**Commit 消息示例**：

```bash
feat: 添加时间范围检索功能
fix: 修复 Python 3.9 兼容性 bug
docs: 更新 API 文档
test: 添加批量操作测试用例
chore: 更新依赖版本
refactor: 优化检索算法性能
```

### 4. 添加测试（中级）

**测试贡献**：

```python
# 示例：添加测试用例
def test_retrieve_note():
    db = MemoryDB.from_home_dir()
    db.add("test:note", "测试内容")
    
    result = db.recall("测试内容")
    assert len(result) > 0

def test_delete_note():
    db = MemoryDB.from_home_dir()
    db.add("test:note", "测试内容")
    db.delete("test:note:1")
    
    result = db.recall("测试内容")
    assert len(result) == 0
```

## 🔧 开发环境设置

### 快速开始

```bash
# 克隆项目
git clone https://github.com/nzq336699/openclaw-memory-pro.git
cd openclaw-memory-pro

# 安装依赖
pip install -r requirements.txt

# 运行测试
pytest

# 启动开发服务器
claw-memory dev
```

### 调试技巧

```bash
# 启用详细日志
export CLAW_MEMORY_LOG_LEVEL=DEBUG

# 查看日志
tail -f logs/memory.log

# 单元测试
pytest tests/ -v
```
