## 🎯 最佳实践 1：构建个人知识库

### 场景：学习管理

```bash
# 1. 创建学习分类
claw-memory create --wing "learn" \
    --room "python" --drawer "basics"
claw-memory create --wing "learn" \
    --room "python" --drawer "advanced"

# 2. 添加学习内容
claw-memory add "learn:python:basics" "Python 基础语法"
claw-memory add "learn:python:advanced" "Python 高级特性"

# 3. 定期复习
claw-memory recall "复习" --since "7 days ago"
```

### 效果

- ✅ 知识自动分类
- ✅ 学习进度可视化
- ✅ 复习提醒自动化

## 🔧 性能优化技巧

### 1. 合理分类

```bash
# ❌ 避免：所有笔记在一个抽屉
claw-memory add "notes" "内容 1"
claw-memory add "notes" "内容 2"

# ✅ 推荐：按主题分类
claw-memory create --wing "work" \
    --room "code" --drawer "python"
claw-memory create --wing "work" \
    --room "code" --drawer "javascript"
```

### 2. 定期清理

```bash
# 清理过期数据
claw-memory clean --older "30 days"

# 归档旧数据
claw-memory archive \
    --since "90 days" \
    --to "archived:2024"
```

### 3. 建立索引

```bash
# 为常用关键词建索引
claw-memory index "Python" "AI" "项目"
```

```bash

# 结果不准确

# ✅ 建议：使用标签 + 关键词
claw-memory recall --tag "urgent" "重要内容"
```

## 🌟 进阶技巧

### 1. 自动化工作流

```bash
#!/bin/bash
# 学习后的自动记录流程

record_learning() {
    local topic=$1
    local content=$2
    
    # 自动分类
    claw-memory add "learn:topics:$(echo $topic | tr ' ' '_')" "$content"
    
    # 自动生成标签
    claw-memory tag "learn:topics:$(echo $topic | tr ' ' '_')" "review"
    
    # 设置复习提醒
    echo "$content" | claw-memory reminder \
        --in "3 days" \
        --tag "review"
}
```

### 2. 批量导入

```bash
# 从文件批量导入
cat notes.txt | while read line; do
    claw-memory add "work:notes" "$line"
done
```

### 3. API 集成

```python
import claw_memory

db = claw_memory.MemoryDB.from_home_dir()

# 定时备份
def backup_daily():
    db.export(f"backups/{datetime.now().strftime('%Y%m%d')}.json")

# 定时清理
def cleanup_weekly():
    db.clean(older="30 days")
```
