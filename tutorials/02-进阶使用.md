## 🔍 高级检索技巧

### 组合检索

```bash
# 多条件检索
claw-memory recall "工作" "重要" --limit 10

# 排除关键词
claw-memory recall "项目" --exclude "临时" "草稿"
```

### 标签检索

```bash
# 检索特定标签
claw-memory recall --tag "urgent"

# 检索多标签
claw-memory recall --tag "work" --tag "important"
```

### 时间范围检索

```bash
# 检索最近 7 天
claw-memory recall --since "7 days ago"

# 检索特定时间范围
claw-memory recall \
    --since "2024-10-01" \
    --until "2024-10-07"
```

## 📦 批量操作

### 批量添加

```bash
# 从文件批量添加
cat notes.txt | while read line; do
    claw-memory add "work:notes" "$line"
done
```

### 批量检索

```python
import claw_memory

db = claw_memory.MemoryDB.from_home_dir()

# 批量检索关键词
keywords = ["Python", "AI", "项目", "笔记"]
for keyword in keywords:
    results = db.recall(keyword, limit=5)
    print(f"{keyword}: {len(results)} 条结果")
```

### 批量删除

```bash
# 删除指定标签的所有内容
claw-memory delete --tag "临时"
```

## 💻 Python API 完整示例

### 基础使用

```python
from claw_memory import MemoryDB

# 初始化
db = MemoryDB.from_home_dir()

# 添加记忆
db.add("work:notes", "今天的笔记")

# 删除记忆
db.delete("work:notes:meeting2024")

# 检索记忆
results = db.recall("会议", limit=2)
print(results)
```

## 📊 性能优化

### 启用缓存

```bash
claw-memory config cache:enabled true
claw-memory config cache:ttl "1 hour"
```

### 建立索引

```bash
claw-memory index \
    "Python" \
    "AI" \
    "项目" \
    "笔记"
```

### 监控性能

```python
import time
from claw_memory import MemoryDB

db = MemoryDB.from_home_dir()

# 测试检索速度
start = time.time()
results = db.recall("测试", limit=100)
print(f"检索耗时：{time.time() - start:.3f}秒")
```

## 🎨 自定义配置

### 配置文件

```yaml
# ~/.claw-memory/config.yaml
cache:
  enabled: true
  ttl: "1 hour"

log:
  level: "INFO"
  file: "logs/memory.log"

sync:
  enabled: true
  interval: "1h"
```
