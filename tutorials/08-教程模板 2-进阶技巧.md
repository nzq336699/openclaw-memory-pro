## 🔧 高级功能

### 1. 多抽屉管理
```python
# 创建多个分类
drawers = [
    db.create(wing="work", room="main", drawer="dev"),
    db.create(wing="life", room="home", drawer="journal"),
]

# 跨抽屉检索
all_memories = db.cross_recall(keywords=["项目", "计划"], drawers=drawers)
```

### 2. 记忆优先级
```python
db.add("重要记忆", "关键信息", priority=1.0)  # 高优先级
db.add("普通记忆", "常规内容", priority=0.5)   # 中优先级
```

### 3. 定时检索
```python
# 设置定时记忆整理
scheduler = db.create_scheduler()
scheduler.every_day(at=9, action="整理今日记忆")
```
