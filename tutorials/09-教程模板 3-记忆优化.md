## ⚡ 性能优化

### 1. 索引优化
```python
# 为常用关键词创建索引
db.create_index(keyword="项目", weight=1.0)
db.create_index(keyword="计划", weight=0.8)

# 定期重建索引
db.rebuild_index()
```

### 2. 缓存策略
```python
# 启用缓存加速检索
db.enable_cache(duration=3600)  # 缓存 1 小时

# 预热常用查询
db.warmup(keywords=["常用词 1", "常用词 2"])
```

### 3. 批量操作
```python
# 批量添加记忆
memories = [
    {"key": "m1", "value": "内容 1"},
    {"key": "m2", "value": "内容 2"},
]
db.batch_add(memories)
```

## 🎯 精准检索技巧

### 布尔搜索
```python
# 多条件检索
results = db.search(
    keywords=["项目", "计划"],
    exclude=["临时", "测试"],
    exact_match=True
)
```

### 模糊搜索
```python
# 模糊匹配
results = db.search(
    keywords="项目*",
    fuzzy=True,
    limit=10
)
```
