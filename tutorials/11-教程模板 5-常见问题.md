# 📚 教程模板 5: 常见问题 FAQ

## 🔧 安装问题

**Q: pip install 报错找不到模块？**

A: 确保已安装 Python 3.8+ 和 pip：
```bash
python3 --version  # 应显示 3.8+
pip3 install openclaw-memory-pro
```

**Q: 权限问题怎么办？**

A: 使用 sudo 或使用虚拟环境：
```bash
python3 -m venv venv
source venv/bin/activate
pip install openclaw-memory-pro
```

## 🎯 使用问题

**Q: 无法创建记忆抽屉？**

A: 检查是否有写权限：
```bash
ls -la ~/.openclaw/memory
# 确保目录可写
mkdir -p ~/.openclaw/memory
```

**Q: 检索结果为空？**

A: 检查是否已添加记忆：
```python
db.add("test", "测试记忆", priority=0.5)
results = db.recall("测试", limit=5)
```

## ⚡ 性能问题

**Q: 检索速度慢？**

A: 启用缓存和优化索引：
```python
db.enable_cache(duration=3600)
db.create_index(keyword="常用词", weight=1.0)
```
