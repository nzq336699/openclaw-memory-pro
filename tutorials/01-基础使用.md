# 🦞 OpenClaw-Memory-Pro 基础使用教程

## 📚 学习目标

- 理解项目核心价值
- 掌握基础用法
- 学会添加和使用记忆

## 🚀 10 分钟快速上手

### 第一步：安装（1 分钟）

```bash
pip install openclaw-memory-pro
```

### 第二步：初始化（1 分钟）

```bash
claw-memory init
```

### 第三步：创建记忆宫殿（2 分钟）

```bash
# 工作记忆
claw-memory create --wing "work" --room "main" --drawer "notes"

# 学习记忆
claw-memory create --wing "learn" --room "study" --drawer "python"
```

### 第四步：添加记忆（1 分钟）

```bash
claw-memory add "work:notes" "今天学习了 AI 开发，很有收获！"
```

### 第五步：检索记忆（3 分钟）

```bash
claw-memory recall "学习"
```

## 💡 核心价值体验

### 1. 永久记忆

```bash
# 添加今天的笔记
claw-memory add "today" "今天的灵感：AI 应该拥有永久记忆"

# 明天再查，依然能找到
claw-memory recall "灵感"
```

**价值**：AI 不会忘记你的任何对话、任何灵感！

### 2. 智能检索

```bash
# 模糊搜索
claw-memory recall "AI"

# 多条件检索
claw-memory recall "工作" "重要"
```

**价值**：毫秒级搜索，快速找到任何知识！

### 3. 结构化存储

```bash
# 创建工作记忆
claw-memory create --wing "work"

# 创建学习记忆
claw-memory create --wing "learn"
```

**价值**：逻辑清晰，分类管理，知识有序！

## 🎯 真实使用场景

### 场景 1：学习管理

```bash
# 添加学习笔记
claw-memory add "learn:python" "今天学习了 Python 的新特性"

# 复习笔记
claw-memory recall "Python"
```

### 场景 2：项目管理

```bash
# 添加会议纪要
claw-memory add "work:meeting" "项目进度：本周完成核心功能"

# 查找会议记录
claw-memory recall "项目"
```

### 场景 3：灵感记录

```bash
# 记录灵感
claw-memory add "inspiration" "AI 应该拥有永久记忆"

# 日后回顾
claw-memory recall "灵感"
```
