## 🔴 安装问题

### Q1: pip install 报错 "PermissionError"

**问题描述**：安装时提示权限不足

```bash
PermissionError: [Errno 13] Permission denied: '...'
```

**解决方案**：

```bash
# 方式 1：使用 --user 参数
pip install --user openclaw-memory-pro

# 方式 2：使用虚拟环境
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
.venv/Scripts/activate      # Windows
pip install openclaw-memory-pro
```

### Q2: Python 版本不兼容

**问题描述**：安装时报错 Python 版本

```bash
ModuleNotFoundError: No module named 'openclaw-memory-pro'
```

**解决方案**：

```bash
# 检查 Python 版本
python --version
# 需要 Python 3.9+

# 使用正确的 Python 版本
python3.9 -m pip install openclaw-memory-pro
```

### Q3: 中文报错

**问题描述**：安装时出现中文乱码或错误

**解决方案**：

```bash
# 设置环境变量
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# 重新安装
pip install --upgrade pip
pip install openclaw-memory-pro
```

### Q4: 依赖缺失

**问题描述**：缺少某些依赖包

**解决方案**：

```bash
# 安装系统依赖
# macOS
brew install pkg-config libomp

# Ubuntu/Debian
sudo apt-get install pkg-config libomp-dev

# 然后安装项目依赖
pip install -r requirements.txt
```

## 🟡 使用问题

### Q5: 命令找不到

**问题描述**：运行命令提示未找到

```bash
command not found: claw-memory
```

**解决方案**：

```bash
# 检查安装路径
python -c "import sys; print(sys.path)"

# 添加路径到环境变量
export PATH=$HOME/.local/bin:$PATH

# 重新初始化
claw-memory init
```

### Q6: 检索不到内容

**问题描述**：添加的记忆无法检索到

**解决方案**：

```bash
# 1. 检查记忆是否添加成功
claw-memory ls

# 2. 检查检索关键词
claw-memory recall "关键词"

# 3. 清理并重新初始化
claw-memory clean
claw-memory init
```

### Q7: 批量导入失败

**问题描述**：从文件批量导入时出错

**解决方案**：

```bash
# 检查文件格式
cat notes.txt | head -5

# 确保每行一个内容
# 使用管道逐个添加
cat notes.txt | while read line; do
    claw-memory add "work:notes" "$line"
done
```

### Q8: 索引搜索慢

**问题描述**：搜索响应很慢

**解决方案**：

```bash
# 启用缓存
claw-memory config cache:enabled true

# 建立索引
claw-memory index "常用关键词"

# 清理过期数据
claw-memory clean --older "30 days"
```

### Q9: 中文显示乱码

**问题描述**：终端显示中文乱码

**解决方案**：

```bash
# 检查终端编码
locale

# 设置正确编码
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# 刷新终端
reset
```

## 🟢 性能问题

### Q10: 检索速度慢

**问题描述**：搜索响应时间过长

**解决方案**：

```bash
# 1. 启用缓存
claw-memory config cache:enabled true
claw-memory config cache:ttl "1 hour"

# 2. 建立常用索引
claw-memory index "Python" "AI" "项目"

# 3. 清理过期数据
claw-memory clean --older "30 days"

# 4. 检查系统资源
top -m
# 确保内存充足
```

### Q11: 内存占用过高

**问题描述**：运行时内存占用大

**解决方案**：

```bash
# 1. 限制缓存大小
claw-memory config cache:max-size "100MB"

# 2. 定期清理
crontab -l
# 添加清理任务
0 2 * * * claw-memory clean --older "30 days"

# 3. 优化索引
claw-memory index --optimize
```

### Q12: 并发访问冲突

**问题描述**：多用户同时访问出错

**解决方案**：

```bash
# 启用并发锁
claw-memory config concurrency:enabled true

# 设置锁文件位置
claw-memory config lock:file "/tmp/claw-memory.lock"
```

## 🟣 其他问题

### Q17: macOS 特定问题

**问题描述**：macOS 上的权限问题

**解决方案**：

```bash
# 处理系统权限
sudo chmod -R u+rwX ~/Library/Application\ Support/claw-memory

# 或使用虚拟环境
python -m venv ~/Library/Application\ Support/claw-memory/venv
```

### Q18: Windows 路径问题

**问题描述**：Windows 上的路径包含空格导致错误

**解决方案**：

```powershell
# 使用双引号包裹路径
"路径包含空格\文件.txt"

# 或设置环境变量
$env:CLAW_MEMORY_PATH = "路径包含空格\venv"
```

### Q19: Linux 权限问题

**问题描述**：Linux 上的文件权限不足

**解决方案**：

```bash
# 重置所有权
sudo chown -R $USER:$USER ~/.claw-memory

# 设置权限
chmod -R 755 ~/.claw-memory
```

### Q20: 数据备份

**问题描述**：担心数据丢失，如何备份

**解决方案**：

```bash
# 导出所有数据
claw-memory export backup/$(date +%Y%m%d).json

# 定期备份
crontab -l
# 添加备份任务
0 3 * * * claw-memory export backup/daily.json
```
