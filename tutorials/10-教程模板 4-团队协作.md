- 知识管理需求者

## 👥 团队协作功能

### 1. 共享记忆空间
```python
# 创建团队记忆空间
team = db.create_team("我的团队")
team.add_member("member1", role="admin")
team.add_member("member2", role="contributor")

# 共享记忆
team.share_drawer("shared_notes")
```

### 2. 权限管理
```python
# 设置访问权限
drawer.set_permission(
    user="member1",
    can_read=True,
    can_write=True,
    can_share=False
)
```

### 3. 评论与讨论
```python
# 添加评论
memory = db.get("shared_notes", "重要会议记录")
memory.add_comment("这是团队的讨论记录")
```
