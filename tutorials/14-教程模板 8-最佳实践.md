## ⭐ 黄金实践

### 1. 命名规范
```python
# ✅ 好的命名
drawer.create(wing="work", room="projects", drawer="my-project-notes")

# ❌ 避免模糊命名
drawer.create(wing="misc", room="stuff", drawer="asdf")
```

### 2. 记忆组织
```python
# 按层级组织
drawers = [
    db.create(wing="work", room="dev", drawer="frontend"),
    db.create(wing="work", room="dev", drawer="backend"),
    db.create(wing="work", room="design", drawer="ui-ux"),
]
```

### 3. 定期整理
```python
# 每日整理
db.daily_maintenance(action="整理今日记忆")

# 每周整理
db.weekly_maintenance(action="清理过期记忆")
```
