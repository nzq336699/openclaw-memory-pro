## 🦞 About OpenClaw

**OpenClaw** is a personal AI assistant that runs on your own devices and connects to all your communication channels.

✨ **Key Features:**
- 📱 **Multi-channel** — WhatsApp, Telegram, Slack, Discord, Signal, iMessage, and more
- 🗣️ **Voice Wake** — Wake up on macOS/iOS/Android with voice commands
- 🎨 **Live Canvas** — Visual workspace for complex tasks
- 🤖 **Multi-agent** — Route tasks to specialized sub-agents
- 🔒 **Local-first** — Your data stays on your devices

## 🚀 Quick Start

```bash
# Install on macOS/iOS
openclaw onboard --install-daemon

# Install on Linux
curl -sSf https://openclaw.ai/install.sh | sh

# Python API
pip install openclaw-memory-pro
```

## 🔒 Security Model

- Default tools run on host for main session
- Sandbox mode for non-main sessions
- Explicit opt-in for unknown DM senders
- Full control over permissions
- Local-first, privacy-focused
