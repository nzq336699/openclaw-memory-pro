## Post 4: 快速开始

```
🦞 Quick Start: Get OpenClaw Running in 5 Minutes

Want to try OpenClaw? Here's a quick 5-minute tutorial:

Step 1: Install
```bash
openclaw onboard --install-daemon
```

Step 2: Connect channels
```bash
openclaw channel connect --platform discord --token <your-token>
```

Step 3: Use voice wake
- macOS/iOS: Say "Hey OpenClaw"
- Android: Use the companion app

Step 4: Explore the Canvas
- Click the menu bar icon
- See your active sessions
- Drag and drop tasks

Step 5: Spawn a subagent
```bash
openclaw agent --task "Summarize this document"
```

📚 Full documentation: https://docs.openclaw.ai/start

## Post 7: 安全特性

```
🦞 Security First: How OpenClaw Keeps Your Data Safe

In a world of cloud dependency, OpenClaw takes a different approach:

Local-First Architecture:
- Your data stays on your devices
- No unsolicited uploads
- User-controlled permissions

Security Model:
- Default DM policy: pairing
- Sandbox mode for non-main sessions
- Explicit opt-in for unknown senders
- Full control over permissions

Encryption:
- AES-256 encryption at rest
- TLS for data in transit
- Local encryption keys
- User-controlled backups

Privacy:
- No telemetry
- No analytics
- No data collection
- Open source, auditable
